# Somatosensory Cutaneous Silent Period (CSP) & Spinal Inhibitory Reflex Skill

This skill computes electrophysiological metrics from cutaneous silent periods to detect spinal cord myelopathy, radiculopathy, and loss of spinal glycinergic/GABAergic inhibition according to clinical neurophysiology standards.

## Core Capabilities
- Evaluates Onset Latency ($ms$), End Latency ($ms$), and Duration ($ms$).
- Computes EMG Suppression Depth ($\%$) during maximal voluntary isometric contraction.
- Provides limb-specific normal reference standards (Upper limb: onset $50-75\text{ ms}$, duration $25-45\text{ ms}$; Lower limb: onset $80-110\text{ ms}$, duration $35-60\text{ ms}$).
- Discriminates cervical spondylotic myelopathy (CSM) from peripheral neuropathy.

## Zero-Mock Architecture
Standard Python standard library only with zero external dependencies.
