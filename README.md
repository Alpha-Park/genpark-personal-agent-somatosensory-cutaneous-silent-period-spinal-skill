# Somatosensory Cutaneous Silent Period (CSP) & Spinal Inhibitory Reflex Skill

A production-grade, zero-mock personal agent skill engineered for clinical neurophysiology, spinal cord dorsal horn inhibitory reflex analysis, and small-caliber $A\delta$ sensory nerve fiber evaluation.

## Features
- **Deterministic Latency & Duration Derivation**: Measures exact onset latency, end latency, and suppression duration in milliseconds.
- **Spinal Myelopathy Sentinel**: Distinguishes focal spinal interneuronal disinhibition from distal peripheral neuropathies.
- **Pure Standard Library**: Zero external dependencies; fully portable for edge and clinical AI deployment.

## Clinical References

- Floeter, M. K. (2003). *Cutaneous silent periods*. Muscle & Nerve, 28(4), 391-401.
